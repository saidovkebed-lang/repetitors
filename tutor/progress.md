## Главное по каждой теме

### 1. Отрицательные числа
- Сложение и вычитание удобно считать через долг. **−1 − 7**: был должен 1, занял ещё 7, итог **−8**. **−3 + 5**: долг 3, получил 5, итог **+2**.
- При умножении минус на минус даёт плюс: (−7)·(−7) = 49.
- **(−7)² = 49**, но **−7² = −49**. Если в формулу подставляешь отрицательное число, бери его в скобки.

### 2. Проценты
- 1% — это одна сотая часть. 10% получается, если убрать один ноль, 5% — половина от 10%.
- Скидка 15%, значит платишь 85% цены: цена · 0,85.
- **Ловушка 1:** чтобы найти исходную цену по цене после скидки, дели: 1400 / 0,7 = 2000. Прибавлять 30% к 1400 неправильно.
- **Ловушка 2:** +25%, а потом −20% возвращают исходную цену (1,25 · 0,8 = 1), а +20% и −20% её уменьшают. Такие случаи всегда проверяй счётом.
- Рост каждый год считается от новой суммы: 3000 · 1,1 · 1,1 = 3630.

### 3. Степени
- aᵐ · aⁿ = aᵐ⁺ⁿ, aᵐ / aⁿ = aᵐ⁻ⁿ, (aᵐ)ⁿ = aᵐⁿ
- a⁰ = 1, a⁻ⁿ = 1/aⁿ, (1/2)⁻³ = 2³ = 8
- Если основания разные, приведи их к одному: 27 = 3³, 9 = 3², 8 = 2³.
- **Ловушка:** 2¹⁰ + 2¹⁰ = 2 · 2¹⁰ = **2¹¹**, а не 2²⁰. Показатели складываются только при умножении степеней.

### 4. Линейные уравнения и неравенства
- Число перед скобкой умножается на каждое слагаемое внутри. Минус перед скобкой меняет все знаки в ней.
- При переносе через знак «=» или «>» слагаемое меняет знак.
- **При делении или умножении на отрицательное число знак неравенства переворачивается:** −6x > −18 → x < 3.
- Ответ неравенства всегда записывается знаком и числом: **x ≥ 8**, а не просто 8.

### 5. Квадратные уравнения
- ax² + bx + c = 0. Выписывай **a, b, c вместе со знаками**.
- D = b² − 4ac. Если D > 0, корней два, если D = 0, один, если D < 0, корней нет.
- x = (−b ± √D) / 2a. **−b — это b с противоположным знаком:** если b = −7, то −b = +7.
- Неполные уравнения: x² = 9 → x = ±3. Уравнение x² − 5x = 0 решай через вынесение x: x(x − 5) = 0. Делить на x нельзя, иначе потеряешь корень 0.
- Если a = 1, корни можно найти подбором пары чисел. Их произведение равно c, а сумма равна b. Корни — эти числа с обратным знаком.
- **Каждый корень проверяй подстановкой.** Это занимает 10 секунд и ловит почти все ошибки со знаками.

### 6. Логарифмы
- logₐ b = c означает aᶜ = b. Логарифм отвечает на вопрос, **сколько раз** нужно умножить основание на себя, чтобы получить число.
- log₂ 64 = **6** (2 → 4 → 8 → 16 → 32 → 64), а не 8.
- logₐ 1 = 0, logₐ a = 1. Логарифма от нуля и от отрицательного числа нет.
- Свойства: log(xy) = log x + log y, log(x/y) = log x − log y, log(xⁿ) = n · log x.
- Уравнение: log₂(x + 1) = 4 → x + 1 = 2⁴ = 16 → x = 15. Логарифм нельзя просто вычеркнуть.
- После решения проверь, что выражение под логарифмом больше 0. Корни, которые не подходят, отбрасывай: в log₂x + log₂(x − 2) = 3 подходит только x = 4.

### 7. Корни
- √a — неотрицательное число, которое в квадрате даёт a. √9 = 3, а не ±3.
- √(ab) = √a · √b, √(a/b) = √a / √b, (√a)² = a.
- Упрощение: √50 = √(25 · 2) = 5√2. Складывать можно только корни с одинаковым числом под знаком: 2√3 + 5√3 = 7√3.
- √(x²) = |x|.

### 8. Модуль
- |x| — это расстояние от x до нуля, оно всегда ≥ 0. Минус перед модулем остаётся: −|−7| = −7.
- |выражение| = a даёт два случая: выражение = a или выражение = −a. Если a < 0, решений нет.
- |x| < a — середина: −a < x < a. |x| > a — края: x < −a или x > a.

### 9. Многочлены и алгебраические дроби
- (a + b)² = a² + 2ab + b², (a − b)² = a² − 2ab + b², a² − b² = (a − b)(a + b).
- Чтобы сократить дробь, разложи числитель и знаменатель на множители и вычеркни одинаковые.
  Пример: (b² − b − 6)/(9b + 18) = (b − 3)(b + 2) / 9(b + 2) = (b − 3)/9, при этом b ≠ −2.
- **Ловушка:** сокращать можно только множители, части суммы нельзя. Поэтому (x² − 9)/(x + 3) = x − 3, а не x − 9.
- На тесте с вариантами ответа можно подставить простое число, например x = 1, в условие и во все варианты.

### 10. Квадратные неравенства
- Алгоритм: найди корни, отметь их на оси, определи знаки на участках и выбери нужные участки.
- Если перед x² плюс (ветви вверх, чашка ∪), знаки идут **+ − +**. Если минус (купол ∩), знаки идут **− + −**. Других вариантов не бывает, а остальные знаки в выражении на это не влияют.
- Знак < 0 означает середину, знак > 0 означает края.
- Строгий знак (<, >) записывается круглыми скобками, нестрогий (≤, ≥) — квадратными: x² − 25 ≥ 0 → (−∞; −5] ∪ [5; +∞).

### 11. Системы уравнений
- **Подстановка:** вырази одну переменную из одного уравнения и подставь в другое.
- **Сложение:** сложи или вычти уравнения так, чтобы одна буква исчезла. Смотри на числа перед одной и той же буквой. Если они не противоположны, домножь одно из уравнений, например верхнее на 2.
- После домножения снова проверь знаки, а в конце подставь ответ в оба уравнения.

### 12. Прямая y = kx + b
- k — наклон (на сколько растёт y, когда x увеличивается на 1), b — точка пересечения с осью y.
- Прямая по двум точкам: k = (y₂ − y₁)/(x₂ − x₁), затем b находится подстановкой одной из точек.
- Пересечение с осью y: подставь x = 0. С осью x: подставь y = 0.
- Точка пересечения двух прямых — это решение системы их уравнений.

### 13. Парабола y = ax² + bx + c
- a > 0: ветви вверх, в вершине минимум. a < 0: ветви вниз, в вершине максимум. В экономике так выглядит максимальная прибыль.
- Вершина: x = −b / 2a, а y находится подстановкой. Пример: y = x² − 4x + 3 → x = 4/2 = 2, y = 4 − 8 + 3 = −1, вершина (2; −1).
- Пересечения с осью x — это корни уравнения ax² + bx + c = 0. Пересечение с осью y — точка (0; c).
- Связь с неравенствами: где парабола выше оси x, там «+», где ниже, там «−».

## Где чаще всего ошибки

1. **Знаки.** Это главный источник ошибок: знак не меняется при переносе, −b берётся без смены знака, теряется минус у второго корня, корни при подборе выписываются с неверными знаками. **Как лечить:** записывай −b отдельной строкой и подставляй каждый корень. 23.11 то же в показательных: −x = 2x + 6 → 2; (1/5)ˣ⁺¹ → 1/3 вместо −1/3. Быстрая проверка знака: оценить, больше или меньше 1 каждая сторона. 24.11 снова: −(x − 2) = −x − 2. Правило: −1 умножается на каждое слагаемое в скобке. Плюс в 2 = 3x делил 3 на 2: x = то, что без x, делённое на число при x.
2. **Логарифм путается с делением или с самим числом.** Ответ на log — это **сколько раз** нужно умножить основание.
3. **Ответ неравенства без знака** или со скобками не того вида.
4. **Сложение степеней по правилу умножения** (2¹⁰ + 2¹⁰).
5. **Сокращение частей суммы в дроби** вместо множителей.
6. **Знаки зон параболы** берутся из выражения, а должны определяться только знаком перед x².
7. **Текстовые задачи по геометрии:** трудно увидеть, где в условии прямоугольный треугольник. **Как лечить:** сначала рисуй картинку и подписывай, какая сторона — гипотенуза. В равнобедренном треугольнике высота делит основание пополам.
8. **В площадь треугольника подставляет боковую сторону вместо высоты** (13 вместо 12). **Как лечить:** высота — только тот отрезок, который падает на основание под прямым углом; если её нет в условии, сначала найди её.
9. **Останавливается на промежуточном шаге** (нашёл сторону 18, а спрашивали площадь). **Как лечить:** в конце перечитай последнюю фразу условия: что именно просят найти.
12. **Отрицание «все» делает как «никто»** (крайнюю противоположность). **Как лечить:** чтобы «все» стало неправдой, хватит одного: «все» → «хотя бы один не».
11. **«Если A, то B»: выбирает «если B, то A» и «если не A, то не B».** **Как лечить:** верна только перестановка с «не» к обеим частям: «если не B, то не A». И на тесте ответ всегда один. Отдельная ловушка: «B only when A» = «если B, то A». 24.11 опять C, потом A (перевернул порядок); помог пример «гуляю only when светит солнце → если гуляю, то солнце». Часть без only идёт после If. Проверка по двум пунктам: после If стоит вторая часть? «не» есть в обеих?
13. **В формуле корней подставляет b² вместо −b** (24.11: (49 ± 1)/2, (−9 ± 7)/4). **Как лечить:** b² только внутри D; сверху −b — просто b с другим знаком.
14. **Логарифм суммы раскладывает как сумму логарифмов** (24.11: log₂(x+6) = log₂x + log₂6). **Как лечить:** склеиваем только log a + log b = log(ab), сумму под логарифмом не трогаем.
16. **x² = число: берёт только положительный корень** (25.11: x² = 4 → 2). **Как лечить:** всегда писать ±.
17. **Умножение уравнения с дробью на знаменатель** (25.11): x/(x−3)·(x−3) записал как x(x−3), +2 не умножил. **Как лечить:** знаменатель сокращается, а на него умножается каждая часть уравнения. Запрещённые x записывать первой строкой.
15. **Корни и модуль:** из √(49·2) выносит 2 вместо 7; при переписывании модуля меняет знак внутри; забыл, что |…| ≥ a — края (два неравенства), ответ пишет «x = …» вместо неравенств.
10. **½ из формулы треугольника переносит на прямоугольник** (216 вместо 432). **Как лечить:** ½ только у треугольника, потому что он — половина прямоугольника.
