## 1. Показательные уравнения (задание 10)

**Идея:** x стоит в показателе степени. Цель — получить **одинаковые основания** слева и справа, тогда равны и показатели.

**Способ 1. Общее основание**
2ˣ⁺¹ = 8 → 8 = 2³ → 2ˣ⁺¹ = 2³ → x + 1 = 3 → **x = 2**

Полезные замены: 4 = 2², 8 = 2³, 16 = 2⁴, 9 = 3², 27 = 3³, 1/4 = 2⁻², 1/9 = 3⁻², 1 = a⁰.

**Способ 2. Замена t = aˣ** (когда есть a²ˣ и aˣ)
4ˣ − 6·2ˣ + 8 = 0. Заметим 4ˣ = (2ˣ)². Пусть t = 2ˣ:
t² − 6t + 8 = 0 → t = 2 или t = 4 → 2ˣ = 2 → x = 1; 2ˣ = 4 → x = 2. **Ответ: 1 и 2.**
Помни: t = 2ˣ всегда > 0, отрицательное t выбрасываем.

**Ловушка — минус перед скобкой**
(1/3)ˣ⁻¹ = 9 → 3^(−(x − 1)) = 3² → −x **+ 1** = 2 → −x = 1 → **x = −1**
−1 умножается на **каждое** слагаемое в скобке: −(x − 1) = −x + 1.
Проверка: (1/3)⁻² = 3² = 9 ✓

## 2. Уравнения с дробями (задание 11)

**Идея:** знаменатель не может быть 0. Поэтому:
1. **Сначала** запиши запрещённые x (знаменатель = 0).
2. Убери дроби: если дробь = дробь, умножай **крест-накрест**; иначе умножь **каждую** часть на знаменатель.
3. Реши и **выброси** запрещённые корни.

**Пример 1:** 2/(x − 1) = 4/(x + 1). Запрещены x = 1 и x = −1.
2(x + 1) = 4(x − 1) → 2x + 2 = 4x − 4 → 6 = 2x → **x = 3** ✓

**Пример 2 (выходит квадратное):** x/(x + 1) = 2/(x + 3). Запрещены −1 и −3.
x(x + 3) = 2(x + 1) → x² + 3x = 2x + 2 → x² + x − 2 = 0 → x = 1 или x = −2. Оба разрешены. **Ответ: 1 и −2.**

**Ловушки:** дробь · свой знаменатель = числитель (знаменатель **сокращается**); число без дроби тоже умножается на знаменатель.

## 3. Прямая y = kx + b (задание 12)

**Идея:** k — наклон (на сколько меняется y, если x вырос на 1), b — где прямая пересекает ось y.

**Алгоритм по двум точкам:**
1. k = (y₂ − y₁) / (x₂ − x₁)
2. Подставь одну точку в y = kx + b и найди b.
3. Ось x: подставь **y = 0**. Ось y: подставь **x = 0** (это точка (0; b)).

**Пример:** точки (−2; 1) и (2; −7).
k = (−7 − 1)/(2 − (−2)) = −8/4 = **−2**
1 = −2·(−2) + b → 1 = 4 + b → b = **−3** → **y = −2x − 3**
Ось x: 0 = −2x − 3 → 2x = −3 → x = −3/2 → **(−3/2; 0)**

**Ловушка:** вычитание отрицательного: 2 − (−2) = 2 + 2 = 4. Проверь: вторая точка должна подойти в уравнение: −2·2 − 3 = −7 ✓

## 4. Парабола y = ax² + bx + c (задание 13)

**Идея:** знак a решает всё.
- a > 0 → ветви вверх ∪ → в вершине **минимум**
- a < 0 → ветви вниз ∩ → в вершине **максимум** (в экономике — максимальная прибыль)

**Алгоритм:**
1. Вершина: x = −b / 2a, y — подставь этот x.
2. Ось x: реши ax² + bx + c = 0 (если a < 0, удобно умножить на −1).
3. Ось y: точка (0; c).

**Пример:** y = −x² + 6x − 5. a = −1, b = 6.
x = −6 / (2·(−1)) = −6/−2 = **3**; y = −9 + 18 − 5 = **4** → максимум **4** в точке (3; 4).
−x² + 6x − 5 = 0 → x² − 6x + 5 = 0 → **x = 1 и x = 5** → (1; 0), (5; 0). Ось y: (0; −5).

**Ловушка:** −3² = −9 (минус не возводится в квадрат, он стоит перед x²).

## 5. Пифагор и ромб (задание 14)

**Пифагор:** в прямоугольном треугольнике c² = a² + b², c — гипотенуза (против прямого угла, самая длинная).
Тройки, которые стоит знать: **3-4-5, 6-8-10, 5-12-13, 8-15-17**.

**Ромб:** 4 равные стороны. Диагонали **делятся пополам** и пересекаются **под прямым углом** → 4 одинаковых прямоугольных треугольника.

**Пример:** диагонали 6 и 8 → половины 3 и 4 → сторона √(9 + 16) = 5 → **периметр 4 · 5 = 20**.
Бонус: площадь ромба = d₁ · d₂ / 2 = 6 · 8 / 2 = 24.

**Ловушка:** берёшь **половины** диагоналей, а не целые. В конце перечитай вопрос: сторона, периметр или площадь?

## 6. Площадь равнобедренного треугольника (задание 15)

**Идея:** S = ½ · основание · **высота**. Боковая сторона — **не** высота.

**Алгоритм:** высота к основанию делит его **пополам** → прямоугольный треугольник: гипотенуза — боковая сторона, катет — половина основания, второй катет — высота.

**Пример:** стороны 5, 5, 6. Половина основания 3. h = √(25 − 9) = √16 = 4. **S = ½ · 6 · 4 = 12.**

**Ловушки:** подставить боковую сторону вместо высоты; остановиться на высоте и не досчитать площадь; ½ — только у треугольника.

## 8. «Only if» и «если… то…» (задание 17)

**Правило:** «A **only if** B» = «**если A, то B**». Часть с *only* — это то, что идёт **после «то»**.

**Из «если A, то B» верно только:** «если **не B**, то **не A**» (обратный порядок + «не» в обеих частях).

**Неверно (ловушки):** «если B, то A» и «если не A, то не B».

**Пример:** «I go out only if it is sunny» → если гуляю, то солнце.
✓ If it is not sunny, I don't go out.
✗ If it is sunny, I go out. (солнце может быть, а я дома)

**Проверка по двум пунктам:** 1) после If стоит вторая часть (B)? 2) «не» есть в **обеих** частях?

## 9. Отрицание (задание 18)

**Идея:** отрицание — это то, что делает фразу **ложной**, а не её крайняя противоположность.

| Фраза | Отрицание |
|---|---|
| Все … (every / all) | **Хотя бы один не …** (at least one … not / not all) |
| Некоторые … (some) | **Ни один …** (no / none) |
| Ни один … (no) | **Хотя бы один …** (at least one / some) |

**Пример:** «All shops are open» → отрицание: «**At least one shop is closed**». Не «All shops are closed»!
Вопрос-подсказка: «Чтобы доказать, что я вру, сколько примеров нужно?» — для «все» хватает **одного**.

## 10. Present Simple vs Present Continuous (задание 19)

| | Present Simple | Present Continuous |
|---|---|---|
| Когда | привычка, факт, расписание | идёт сейчас или в этот период, временно |
| Форма | I/you/we/they **work**, he/she/it **works** | am/is/are + **-ing**: they **are working** |
| Слова-сигналы | usually, always, often, every day, never | now, right now, Look!, Listen!, at the moment, this week/month, currently |
| Отрицание | don't / doesn't + глагол | am/is/are **not** + -ing |

**Примеры:**
- Inflation usually **grows** slowly. (обычно)
- Look! The shop **is closing**. (прямо сейчас)
- This year the company **is hiring** more people. (этот период)

**Ловушки:** не забывай **am/is/are** перед -ing; **-s** у he/she/it в Simple; глаголы состояния (know, like, want, need, believe) почти не бывают с -ing: I **know**, не *I am knowing*.
