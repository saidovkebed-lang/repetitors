# repetitors

Персональный агент **«Репетитор»** для Claude Code.

- `.claude/agents/personal-tutor.md` — инструкции агента
- `tutor/progress.md` — что уже пройдено, типичные ошибки, место, где остановились, и задания на повторение

## Как обратиться к агенту

Открой сессию Claude Code в этом репозитории и напиши, например:

> Используй агента personal-tutor: вот задание …

> @personal-tutor С нуля: проценты

Команды на занятии: «С нуля», «Подсказка», «Реши полностью», «Проверь меня», «Коротко», «Газ».
